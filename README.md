# etzhayyim Resource Provider Project

This project establishes the etzhayyim Resource Provider Network, a decentralized system where users can contribute various resources in exchange for rewards.

## Core Resources
- **Documents & Images**: For RAG and AI model training.
- **Compute (GPU)**: Powering decentralized AI inference and training via WebGPU.
- **Location Data**: Real-time geographic insights and analytics.

## Project Structure
- `PROJECT.jsonld`: Project metadata and task tracking.
- `STRATEGY.jsonld`: Strategic roadmap and milestones.
- `ARCHITECTURE.jsonld`: System architecture and data flow.
- `capabilities.jsonld`: Defined capabilities and measures.
- `activities.jsonld`: Operational activities and performers.
